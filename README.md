# AWG Home Local for Mac

Локальное приложение с кнопками «Подключить» и «Отключить» для одного личного профиля AmneziaWG. Оно не использует Apple Network Extension и не требует платной Apple Developer Team. Окно написано на Cocoa; при установке сетевой движок копируется из уже установленного `/Applications/AmneziaVPN.app`, а настройка протокола выполняется официальным `awg` из [amneziawg-tools](https://github.com/amnezia-vpn/amneziawg-tools), commit `ee0f0a9` (GPLv2; исходники и лицензия находятся в `vendor/amneziawg-tools`). Репозиторий не содержит движок AmneziaVPN и VPN-профили.

Приложение **не содержит закрытого ключа**. Установщик один раз копирует выбранный профиль в закрытый файл `/Library/Application Support/AWG Home/client.conf` с правами `0600` и ставит небольшого помощника под `root`. При каждом нажатии «Подключить» или «Отключить» macOS запросит пароль администратора. Серверы и роутер установщик не меняет.

## Установка на другом Mac

Нужен Mac с правами администратора, установленными [Command Line Tools для Xcode](https://developer.apple.com/xcode/resources/) и официальным AmneziaVPN в `/Applications/AmneziaVPN.app`. Полная Xcode и платная учётная запись Apple Developer не нужны. Исходники собираются **на том Mac, где приложение будет работать**; готовый `.app` с другого Mac копировать не требуется.

Скачайте этот репозиторий через GitHub (**Code → Download ZIP**) и распакуйте его. Откройте Терминал в распакованной папке и выполните:

```sh
./build.sh
sudo ./install.sh "$HOME/Downloads/awg-mac-new.conf"
```

Замените путь во второй строке на путь к **личному AWG-профилю именно этого Mac**. Профиль содержит закрытый ключ: не кладите его в папку репозитория, не отправляйте на GitHub и не публикуйте скриншоты с его содержимым. Для одновременной работы двух Mac каждому нужен отдельный peer/профиль на сервере. Установщик копирует профиль в закрытое системное хранилище и не меняет сервер или роутер.

Затем откройте `build/AWG Home.app` из Finder. Выключите другой VPN и нажмите «Подключить». При каждом изменении подключения macOS запросит пароль администратора. Если macOS предупреждает о неподписанном приложении, откройте его через Finder → контекстное меню → «Открыть». Сборка подписывается локальной ad-hoc подписью, а не сертификатом Apple Developer.

### Смена профиля

В этой версии приложение хранит только один активный профиль. Сначала нажмите «Отключить», затем в папке проекта выполните `sudo ./install.sh "$HOME/Downloads/другой-профиль.conf"`, указав реальный путь к новому `.conf`. Установщик заменит закрытую локальную копию профиля; после этого нажмите «Подключить». Пока туннель включён, установщик откажется заменять профиль. Переключателя между несколькими профилями в окне пока нет.

Чтобы удалить приложение с этого Mac, в той же папке выполните `sudo ./uninstall.sh`, затем удалите папку проекта. Если после включения пропал интернет, сначала нажмите «Отключить» либо выполните `sudo /usr/bin/python3 /Library/PrivilegedHelperTools/awg-home/awg_home_helper.py stop`.

## Состояние и ограничения

Исходники и окно собраны для проверки на одном Mac. Туннель этой сборкой **ещё не запускался**, поэтому живое подключение на другом Mac **не подтверждено**. Помощник откажется включить AWG Home поверх другого VPN. После отключения другого VPN потребуется проверка подключения и восстановления маршрутов.

Сборка рассчитана на полный **IPv4**-профиль. Она не включает IPv6 в туннель, не имеет kill switch и не является заменой полнофункциональному VPN-клиенту до успешного испытания. При потере движка или смене основного маршрута фоновый сторож пытается убрать маршруты и вернуть прежний DNS. Если интернет пропал, нажмите «Отключить» или выполните `sudo /usr/bin/python3 /Library/PrivilegedHelperTools/awg-home/awg_home_helper.py stop`.

## Исходники и проверка

Сборка: `./build.sh`. Проверка парсера и защитных условий: `python3 -m unittest discover -s tests`. Включённые исходники `amneziawg-tools` распространяются по GPLv2; их лицензия находится в `vendor/amneziawg-tools/COPYING`. Скрипт `uninstall.sh` сначала отключает созданный им туннель и восстанавливает маршруты/DNS; если это не удастся, удаление остановится, чтобы сохранить возможность повторить откат.
