# Промты для соседних чатов

Файлы можно целиком скопировать в новый чат. Перед отправкой добавьте только
необходимый контекст, но не вставляйте private keys, UUID, URI, QR-коды,
пароли или токены.

- [`awg-setup-agent.md`](awg-setup-agent.md) — установка или восстановление AWG.
- [`vless-reality-agent.md`](vless-reality-agent.md) — настройка VLESS REALITY.
- [`vpn-diagnostics-agent.md`](vpn-diagnostics-agent.md) — диагностика без
  поспешных перезапусков.
- [`vpn-project-handoff.md`](vpn-project-handoff.md) — общий перенос контекста
  проекта в другой чат.

Промты специально требуют read-only аудит и отдельное разрешение на установки,
перезапуски и любые удаления.
