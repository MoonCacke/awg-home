# Обезличенные примеры

Все значения в угловых скобках нужно заменить. Файлы не предназначены для
прямого запуска без проверки интерфейсов, портов, версий и firewall.

- `awg-server.conf.example` — AWG-сервер.
- `awg-client.conf.example` — отдельный клиент.
- `awg-nftables.nft.example` — минимальный forward/NAT.
- `xray-server-reality.json.example` — VLESS REALITY на Xray.
- `xray-client-reality.json.example` — локальный SOCKS-клиент Xray.

Никогда не переименовывайте заполненные файлы в обычные `.example` ради
публикации: заполненный шаблон уже является секретом.
